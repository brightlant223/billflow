# Cal — Orange Glass Calculator

A responsive calculator app built with React and Vite, styled with a warm orange gradient and glassmorphism.

## Features
- Addition, subtraction, multiplication, and division
- Decimal input, sign toggle, percentage, clear, and backspace
- Keyboard support: digits, `+`, `-`, `*`, `/`, `Enter`, `Backspace`, `Esc`, and `%`
- Recent calculation history with one-tap result restore
- Copy current result
- Responsive desktop and mobile layout
- Accessible button labels and reduced-motion support

## Run locally
Requires Node.js 18 or newer.

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

## Stack
- React
- Vite
- Lucide React icons
- CSS glassmorphism and orange gradient styling
